# Security policy

## Project scope

This repository is the [ZEACENT fork of klogg](https://github.com/ZEACENT/klogg).
**GitHub is this project's only communication channel.** Upstream email addresses,
chat groups, and reporting keys are not contacts for this project.

Current packages and release notes are on
[GitHub Releases](https://github.com/ZEACENT/klogg/releases). This document does
not establish a long-term-support period or promise security backports for older
versions. The former upstream 20.12 support table did not describe this fork's
current calendar-versioned releases.

## Reporting a vulnerability

Do **not** publish sensitive vulnerability details, private logs, credentials,
or device identifiers in a public issue.

Check the repository's [Security page](https://github.com/ZEACENT/klogg/security).
Use GitHub's private vulnerability reporting option only if it is available.
If it is not, open a minimal
[GitHub issue](https://github.com/ZEACENT/klogg/issues) asking the maintainer to
enable a private GitHub reporting channel. Do not include the vulnerability,
exploit steps, or sensitive attachments in that public request; wait until a
private GitHub channel is available before sharing them.

This documentation does not imply that private vulnerability reporting is
currently enabled. Ordinary, non-sensitive bugs can be reported directly in
GitHub Issues using the [contribution guide](CONTRIBUTING.md).
